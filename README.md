# Streaming Content Trend Analysis (Netflix, Prime, Hotstar) 🎬[span_9](start_span)[span_9](end_span)

## 📌 Project Overview
An exploratory data analysis (EDA) project evaluating streaming platform content catalogs to uncover patterns in genre popularity, content ratings, and yearly growth trends[). This project mimics workflows executed by real-world content strategy and growth teams

## 🛠️ Tools & Technologies
* **Python**: Pandas, Seaborn, Plotly
* **SQL**: For data aggregations and joins
* **Environment**: Visual Studio Code / Jupyter Notebook

## 📊 Key Objectives & Analysis
* Cleaned and preprocessed raw catalog data to handle missing values and format timestamps.
* Analyzed the distribution and ratio of Movies vs. TV Shows across platforms).
* Visualized genre popularity shifts over the years using Seaborn and Plotly
* Derived actionable business insights regarding content catalog expansion

## 🚀 How to Run
1. Clone this repository.
2. Install required packages: `pip install pandas seaborn matplotlib plotly`
3. Run the analysis script or notebook to view the visualizations.
